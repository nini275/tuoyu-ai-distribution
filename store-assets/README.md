# Microsoft Store Asset Pack

This directory contains draft materials for a Microsoft Store submission. It is not proof that TuoYu has been submitted, certified, or published.

## Included

- `listing/en-US.md`: English Store listing draft
- `listing/zh-CN.md`: Simplified Chinese Store listing draft
- `screenshots/`: current desktop screenshots when present

## Still Required

- Final Partner Center Package Identity and Publisher ID
- Store product name reservation
- Signed MSIX/AppX package generated from the Partner Center identity
- Final support and privacy URLs
- A monitored support email
- Store age-rating questionnaire
- Final CNY prices and Store add-on IDs
- Release notes for the submitted version

The icon sources are in `icons/`. The generated PWA icons are suitable for packaging input, but the Microsoft packaging tool may generate additional Windows scale assets.
