## Description

TuoYu is a distribution workspace for software, AI models, and open-source projects. Its Rita distribution agent helps publishers organize project facts, assess channel fit, prepare channel-specific drafts, and review every external publishing action before it happens.

TuoYu also includes an MCP tool catalog. Approved projects can be searched by compatible AI clients through structured `search_tools` and `recommend_tools` interfaces. Paid placement, when enabled after review, is clearly disclosed and separates promotional ranking from organic relevance.

Use TuoYu to:

- Create a structured project profile with links, audience, category, and use cases
- Review channel-fit suggestions for developer, model, and content platforms
- Generate channel-specific launch drafts
- Edit, review, schedule, and record publishing decisions
- Prepare machine-readable project facts, FAQ prompts, and JSON-LD
- Explore an MCP catalog for project discovery by AI tools

TuoYu improves information completeness and discoverability. It does not inject results into ChatGPT, Claude, Gemini, Cursor, or another AI product, and it cannot guarantee a recommendation, ranking, citation, or inclusion.

Plan previews in the current build are local interface previews. Microsoft Store subscription products and receipt verification must be completed in a submitted Store build before paid plans can be offered.
