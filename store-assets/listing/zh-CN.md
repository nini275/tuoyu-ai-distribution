# Microsoft Store 商品页文案 - 简体中文

## 商品名称

TuoYu

## 分类

开发人员工具

## 简短说明

使用 Rita 为软件、模型和开源项目规划可被 AI 理解的项目信息与分发内容。

## 详细说明

TuoYu 是面向软件、AI 模型和开源项目的分发工作台。Rita 分发智能体帮助发布者整理项目事实、判断渠道适配度、生成针对不同渠道的内容草稿，并在执行任何外部发布动作前保留人工审核。

TuoYu 还提供 MCP 工具目录。审核通过的项目可通过结构化的 `search_tools` 和 `recommend_tools` 接口被兼容的 AI 客户端检索。若启用付费推广，目录会明确标识推广位置，并将付费加权与自然相关性区分开。

主要功能：

- 创建包含链接、目标用户、分类和使用场景的项目档案
- 获取面向开发者、模型和内容渠道的适配建议
- 生成针对不同渠道的发布内容草稿
- 编辑、审核、排期并记录发布决定
- 准备机器可读的项目事实、问题提示和 JSON-LD
- 通过 MCP 工具目录改善项目信息的结构化发现

TuoYu 帮助提高项目信息的完整度和可发现性，但不会向 ChatGPT、Claude、Gemini、Cursor 或其他 AI 产品直接写入结果，也不保证获得推荐、排名、引用或收录。

当前版本中的套餐页面为本地界面预览。正式上架版本必须先完成 Microsoft Store 订阅商品配置和服务器端购买凭证验证，方可向用户收取真实订阅费用。
